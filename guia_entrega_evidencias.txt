7. ARCHIVO ZIP PARA LA PLATAFORMA (INCLUIR .git)

El ZIP debe contener la carpeta del proyecto y su historial `.git`, pero no
debe contener `.venv` ni `data\bronze`. No incluir bases de datos, caches o
descargas innecesarias. La carpeta data\sample si debe incluirse.

En Windows, una forma segura es crear una carpeta temporal nueva y copiar el
proyecto excluyendo solo las dos carpetas indicadas. Desde PowerShell, parado
en la raiz del repositorio, adaptar y ejecutar:

    $origen = (Get-Location).Path
    $staging = Join-Path $env:TEMP "pi4-observatorio-entrega"
    $destino = Join-Path $staging "pi4-observatorio-energia"
    New-Item -ItemType Directory -Force -Path $destino | Out-Null
    robocopy $origen $destino /E /XD "$origen\.venv" "$origen\data\bronze"

Robocopy puede devolver codigos 0 a 7 cuando la copia fue correcta. Luego
crear el ZIP fuera de la carpeta staging; Get-ChildItem -Force permite incluir
la carpeta oculta `.git`:

    $zip = Join-Path $env:USERPROFILE "Desktop\pi4-observatorio-entrega.zip"
    Compress-Archive -Path (Get-ChildItem -Force $destino | ForEach-Object { $_.FullName }) -DestinationPath $zip -Force

Antes de subir, abrir el ZIP y comprobar:
[ ] Existe la carpeta `.git` dentro de la carpeta del proyecto.
[ ] NO existe `.venv`.
[ ] NO existe `data\bronze`.
[ ] Existen README.md, src, tests, docs\perfilamiento.md y data\sample.
[ ] El archivo ZIP se puede abrir y su tamano parece razonable.

No compartir el ZIP por un enlace publico si contiene datos internos de
EnerAndes. Para la plataforma, seguir la politica de entrega del curso.
